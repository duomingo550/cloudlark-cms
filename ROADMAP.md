# Roadmap

Cloud Lark CMS is currently an early-alpha foundation. Priorities may change
after real user feedback.

## Near term

- Improve first-run setup and environment validation
- Add PostgreSQL migration instructions
- Add S3-compatible storage adapter example
- Add automated tests for access control and section rendering
- Improve empty states and onboarding
- Document common content-model extensions

## Next

- Static release generation and rollback
- Custom-domain verification and HTTPS guidance
- Contact forms and lead inbox
- Audio size, duration, and storage quotas
- Background audio transcoding
- Import and export

## Later

- AI-assisted page and content drafting
- Download entitlements and payment integrations
- Theme/template packages
- More chart, comic, and media workflows
- Team roles and site-owner self-service

## Not planned

- A freeform arbitrary-HTML page builder
- A WordPress-compatible plugin ecosystem
- Full commerce, tax, and fulfillment in the core
- DRM or a music streaming platform
